## What changed since 2.0.0.3

### New

- **Audio previews for shared presets.** Giving a preset an audio preview is now much easier: Atlas can make it for you. The Share patch form has a Preview group, where Preview source offers three options:
  - **Generated notes:** Atlas plays the patch itself and records it. Preview notes is a single C held for two seconds, or one of 19 MIDI files that come with Atlas (melodies, legato lines, bass lines, chords, held notes, mod wheel, pitch bend), all in C minor. Preview octave picks the C, from C1 to C7.
  - **MIDI file:** Atlas plays your own MIDI file, up to 60 seconds, moved up or down by Preview octave.
  - **Audio file:** your own recording (WAV, AIFF, FLAC, MP3, Ogg, Opus, M4A or AAC, up to 40 MB), sent as it is.

  Play preview lets you hear it before you share.

### Changed

- **Autoload preset when scrolling is remembered** for every instance and the next session.
- **The preset browser keeps its place** in a duplicated Atlas and in a project opened again: the same bank and the same preset.

### Testing on Windows

This build has not been tested on Windows yet. If you use Atlas on Windows, please share a preset with a preview, trying each Preview source, and tell us whether everything works and whether Atlas uses a lot of CPU or lags while it makes or plays the preview.
