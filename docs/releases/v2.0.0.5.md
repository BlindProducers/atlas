## What changed since 2.0.0.4

### New

- **Cycle blend frame style.** In the wavetable editor, an Audio file source's Frame blend has a fifth option, Cycle blend. Each frame is a whole cycle of the audio, with the next cycle blended into its start, so every frame loops without a click and neighbouring frames line up. A table that uses Cycle blend does not play correctly in Atlas 2.0.0.4 or earlier.

### Fixed

- **Synthesize preset to wavetable moves evenly from frame to frame.** Each frame started at a different point in the waveform's cycle, so the sound changed unevenly as Wave frame moved. Resynthesis now uses Cycle blend. Tables made with an earlier version keep their old frames: synthesize them again.
- **Smooth Interpolation works.** It did nothing, so a wavetable always jumped from one frame to the next. With it on, a position between two frames now plays a blend of both. With it off, wavetables play as before.
