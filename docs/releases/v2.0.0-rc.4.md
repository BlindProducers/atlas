## What changed since RC 3

### Fixed

- **Wavetable editor Frame slider.** The Frame slider kept the frame count the wavetable had when the editor was shown: on the default table it stopped at 7, however many frames the keyboard editor added or deleted, and it did not follow the frame the arrow keys, Home and End moved to. It now always goes from 1 to the table's frame count and shows the frame you are on, also after undo and redo, and the Frame timeline position slider shows that frame's position.
