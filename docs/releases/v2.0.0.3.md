## What changed since 2.0.0.2

### New

- **Filters: Band Reject model.** Filter 1, Filter 2 and Filter FX have a Band Reject model after Distortion: a lowpass below Cutoff and a highpass above it in parallel, each soft clipping its input, so Cutoff sits in a notch. Blend is the width of the notch, shown as Width in percent: 1.3 semitones at 0% and 128 semitones at 100%. Resonance works as in the other models, up to a sharp notch at 100% that never self-oscillates, and Drive is the gain into the soft clip. Key Track and Mix work as usual. Older presets load as before. Host automation written for a filter's Model in an earlier version needs redrawing, since the menu has one more option.

### Fixed

- **Period stuck on Macros, Modulation, Presets and Global.** These groups have one section, laid out flat, so period on their heading found the same heading again and stayed, and from a control in the group it reached the heading and stopped. Period now steps on to the next section. Comma was unaffected.
