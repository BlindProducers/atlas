## What changed since RC 5

### New

- **Factory presets.** The installers install the Factory bank, 350 presets in 12 categories: Arp (20), Bass (80), Bell (20), Chords (27), Drone (20), FX (20), Keys (20), Lead (52), Organ (20), Pad (30), Pluck (21) and Sequence (20). They go to the Factory library, in `Factory/Banks/Factory` in the Atlas folder (`Documents/Blind Producers Plugins/Atlas`). Installing again replaces the Factory presets with the installer's copies and leaves everything else alone, so save your own versions of them in your User library.
- **The library folders.** The installers create the Factory, User, Third Party and Community libraries, each with its Banks, Wavetables, Multisamples, Samples, LFO Presets, FX Presets and Impulse Responses folders, so you can drop files into them before Atlas first runs.
