## What changed since 2.0.0

### New

- **Arpeggiator Swing.** Each arpeggiator has a Swing control after Free rate, from 0% to 100%. It delays every second step, by a quarter of a step at 50% and by half a step at 100%, and the step before it lasts that much longer. It works in Sync and in Free time. With Retrigger set to Beat, the first step after each restart stays on the beat. At 0%, the default, older presets play as before.
- **Arpeggiator Gate up to 200%.** Gate now goes from 1% to 200%. Above 100% a note lasts into the next step, so the notes overlap. With Polyphony at 1 and Legato on, overlapping notes play as one legato note, as overlapping keys do: the envelopes do not restart, and Portamento glides between them. With Retrigger set to Beat, every note ends where the pattern restarts, so the restart always starts a new note.
- **LFO Sync: Hertz.** An LFO's Sync has a Hertz option after Seconds. It runs the LFO at the same free rate as Seconds, and Frequency reads and takes its value in Hz, from 0.0078 Hz to 512 Hz, instead of seconds. Switching between Seconds and Hertz keeps the rate. Older presets load as before. Host automation written for an LFO's Sync in 2.0.0 needs redrawing, since the menu has one more option.
- **Library location.** Settings has a Library location group: the folder Atlas keeps its library in, Choose library location and, while the library is not in the default folder, Reset library location, which moves it back. Choosing a folder moves the whole library there. An empty folder becomes the library, and any other folder gets an Atlas folder inside it. On the same disk the move is immediate. Onto another disk Atlas copies the library, checks every file and only then removes the old folder; meanwhile the group shows how far the move is, with Cancel library move. A failure or a cancel leaves the library where it was. Favourites follow, and a project saved before the move still finds its instruments. A folder that already holds an Atlas library is used as it is, and the two are never merged. Other instances in the same host follow at once. Another host that was open during the move follows when its preset browser next gets the focus, or after a restart. The installers still put the Factory presets in Documents/Blind Producers Plugins/Atlas, and Atlas takes them into the library the next time it opens, unless that folder holds anything else. If the library's folder is missing, on a drive that is not plugged in, Atlas says so, uses the default folder until the drive is back and keeps the setting.
- **Previous and Next instrument.** A Multi-sample slot's Instrument group has Previous instrument and Next instrument buttons after Browse instruments. For an instrument in a library's Multisamples folder they step through all of that library's instruments, whatever folders they are in. For a file loaded from another folder they step through the SFZ, DecentSampler and SF2 files beside it. They wrap around at the ends, and are dimmed when there is no other instrument.
- **Distortion: eight new Types.** The Distortion effect's Type menu has Tube, Diode 1, Diode 2, Zero-Square, Asymmetric, Stomp Box, Tape Saturation and Soft Saturation after Down Sample. With one of them selected, Drive goes from 0% to 100% and a Level row in dB follows Mix; Mix and the filter work as for the other Types. At Drive 0% and Level 0 dB they play a quiet input at about its own level, except Diode 2, which is silent at Drive 0%. Changing between these Types crossfades. They run 4 times oversampled and add 7 samples of latency, which Atlas reports to the host. Older presets load as before. An automation slot assigned to Distortion's Type in 2.0.0 needs redrawing, since the menu has eight more options.

### Changed

- **Arpeggiator notes follow Polyphony.** An arpeggiator's notes used to play outside the Polyphony limit. Each oscillator slot's arpeggiator notes now follow Polyphony, Legato and Voice Override on their own, as played keys do together. With Polyphony at 1 an arpeggio plays one note at a time, and a Chord Trigger of four keys with Polyphony at 2 plays two notes. Notes that are still releasing count too, so a preset whose arpeggio relied on long release tails, or on a chord larger than Polyphony, sounds different until you raise Polyphony.
- **LFO and Random rate rows follow Sync.** An LFO's Custom view showed every rate row, whatever its Sync, and so did the Random generators. Both now show only the rows Sync uses, as the LFO's Simple view does: Frequency for Seconds, Tempo for Tempo, Tempo Dotted and Tempo Triplets, and Keytrack Transpose and Keytrack Tune for Keytrack.
- **LFO Phase and Stereo read in percent.** Phase read 0 to 1 and Stereo -0.5 to 0.5. Both now read from 0% to 100%, with Stereo's middle at 50%, and take a typed percentage. The stored values are the same, so presets and automation are unchanged.
- **A Random generator's 10x Rate is a toggle,** as an LFO's is. It was a slider.
- **Destroy starts at Drive 0% and Level 0 dB.** A new Destroy started at Drive 25%, and its Level read 0 dB where the distorted signal was 8.6 dB quieter than the input. Level now reads the distorted signal's gain against the input at Drive 0%, so 0 dB plays a quiet input at its own level, and it goes up to +3.4 dB. Presets and projects saved in 2.0.0 sound as before; their Level reads 8.6 dB lower than it did.
- **Space in the preset browser goes to the host.** Space in the preset table loaded the selected preset, as Return does, so the host never got the key. Space now does nothing in the preset table and in the Collection, Library, Bank, Category and Tags tables, and reaches the host, where it usually starts and stops playback. Return still loads a preset.

### Fixed

- **Speech with an arpeggiator and one voice.** With Polyphony at 1, a Speech oscillator's arpeggiated syllables ran into each other, with Legato on or off, because the arpeggiator's notes ignored Polyphony. They now play one at a time.
- **Filter Blend names what the Style plays.** Blend read Low pass, Band pass and High pass in every Style, so Notch Blend said Band pass where it plays a notch. On the Analog, Dirty, Ladder and Digital models it now reads Low pass, Notch and High pass in Notch Blend; Band pass, Two notches and Notch in Notch Spread; and Band pass, Peak and Notch in B/P/N. Phaser reads its 4, 8 and 12 stages. Where Blend is an amount rather than a move between responses, as on Diode and the Comb's Band Spread styles, it reads from 0% to 100%. You can type a name or a number, and the stored value is unchanged.
- **Plugin info on a release.** Atlas 2.0.0 showed "2.0.0 RC 5" under Plugin info in Settings. A release now shows its version alone; a pre-release still shows its beta or RC number.
- **Comma and period after a group shortcut.** Comma and period stepped from the section a shortcut last reached. After F for Filters, or after Tab into another section, they went back to where you were before: from Envelope 3, F and then period reached Envelope 4. They now start from where the focus is, and on a group's heading period goes into its first section. The number keys choose a section of the group the focus is in, too.
- **DecentSampler envelopes written as ampEnv.** A preset can write its envelope as `ampEnvAttack`, `ampEnvDecay`, `ampEnvSustain` and `ampEnvRelease`. Atlas ignored these, so such a library played with the default envelope and a 0.1 s release. They are read now, and win over the plain spelling as in DecentSampler, along with `ampEnvDelay` and `ampEnvHold`.
- **DecentSampler release samples by hold time.** `loHoldTime` and `hiHoldTime` choose a release sample by how long the key was held. Atlas ignored them, so every release sample of a key played at once. Under the sustain pedal Atlas counts the time up to the pedal lifting.
- **Notes with no release no longer cut off in a millisecond.** SFZ and SF2 instruments that set no release default to 1 ms, which Atlas played as written and which could click, most on low notes. A Multi-sample release is now never shorter than 6 ms, and an SF2 release never shorter than about 16 ms, as in sfizz and FluidSynth.
