## What changed since RC 2

### New

- **Frozen phase randomization.** Each oscillator has a Phase Randomization Mode after Phase Randomization. New Each Note, the default, draws new random phases for every note as before, so older presets load and sound unchanged. Frozen starts every note's unison oscillators from the same random phases, like a rendered unison sample played back from a sampler: repeated notes and the notes of a chord all start alike, and since detune is in cents the beating scales with pitch as a resampled recording's would. Phase Randomization still sets how far the phases spread. **Phase Randomization Seed** (0 to 65535), shown only while Frozen, picks the pattern, and a **Randomize phase seed** button after it picks a new one, as the Random Amplitudes seed does. A seed sounds the same on every platform and in every render. Wavetable and Analog oscillators both use it, and every existing host parameter ID stays put.
- **Unison Remove Fundamental.** Wavetable oscillators have an Off/On switch after Unison Blend. On, it takes the first harmonic out of every detuned unison voice, so wide unison and Reese basses keep a steady low end while the upper harmonics still beat. Only a voice on the note's pitch keeps its fundamental: the middle voice of an odd count. With an even count every voice is detuned and none keeps it, and a single voice is left whole. Warps apply afterwards, so Sync, Bend or FM can bring some low end back. Off, the default, leaves older presets as they were; Analog oscillators have no wave buffers and hide the switch.

### Fixed

- **Unison random phase on Apple Silicon.** Phase Randomization spread the unison phases over the whole cycle on Windows but not on Apple Silicon, where half the unison oscillators started every note exactly in phase and the rest only in the first half of the cycle, so even 100% left the stack strongly coherent and unison sounded less smooth than on Windows. Mac now matches Windows.
